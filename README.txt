HOW TO RUN THE RELEASE
--------------------------------------------------------------------------------
Option 1: Live Browser Play (Recommended)
1. Open any modern desktop web browser (Google Chrome, Microsoft Edge, or Mozilla Firefox).
2. Navigate to the hosted WebGL URL:
   https://nouzen214.github.io/PAMANA/
3. Allow the game assets and WebAssembly bundle to load in the browser.

Option 2: Local Web Server
1. Extract the contents of "Pamana-v0.1.0.zip" into a local directory.
2. Double-click "run_webgl.bat" or run a simple HTTP server (e.g., Python: "python -m http.server 8000").
3. Open your browser and navigate to: http://localhost:8000/index.html

--------------------------------------------------------------------------------
GAMEPLAY CONTROLS
--------------------------------------------------------------------------------
Movement:
- W / A / S / D or Arrow Keys: Walk in 4 directions
- Virtual Joystick: On-screen touch / drag (mobile/touchpad)

Interactions:
- E / Space / Enter: Interact with pedestals, plaques, and portal
- Mouse Click: Select artifacts, choose quiz answers, open/close bag
